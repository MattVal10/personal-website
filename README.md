# Personal Website

My personal portfolio website, built using **HTML, CSS, and
JavaScript**, and deployed through **Vercel**.

I'm a Computer Science and Philosophy student at the
University of Washington. This website is a place to share
my experience, projects, leadership activities, and photography.

## What's Included

- **About Me:** A little about my background and interests.
- **Experience:** My work in research, networking, and teaching.
- **Projects:** Projects I've worked on, including Nurture.
- **Leadership:** My involvement as an Engineering Design Coach
  and Nordic Scholar.
- **Photography:** A collection of some of my favorite photos.
- **Contact:** Links to my email, LinkedIn, and resume.

## Built With

- **HTML** — Website structure
- **CSS** — Styling and responsive layout
- **JavaScript** — Interactive features and theme toggle

## Deployment

This website is hosted on **Vercel** and connected to GitHub.
Updates pushed to the `main` branch are automatically deployed
through Vercel.

## Features

- Responsive layout for desktop and mobile
- Light and dark mode toggle
- Downloadable resume
- Links to projects and professional profiles
- Photography gallery

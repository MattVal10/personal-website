MATTHEW VALENCIA — PORTFOLIO

Open index.html in your browser, or use VS Code Live Server.

FILES
index.html  - Website content
styles.css  - Colors, layout, responsive styling
script.js   - Theme toggle and copyright year
assets/     - Resume PDF and your own photos

ADDING PHOTOS
1. Copy a photo into assets/, for example assets/stockholm.jpg.
2. In index.html, find the photo-grid section.
3. Replace one placeholder div with:
   <img class="gallery-photo" src="assets/stockholm.jpg" alt="Street scene in Stockholm">
4. Add the CSS below to styles.css:
   .gallery-photo { width: 100%; aspect-ratio: 3/4; object-fit: cover; border-radius: 14px; }

EDITING
Edit text in index.html, colors and layout in styles.css, and theme behavior in script.js.
